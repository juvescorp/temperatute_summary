# temperatute_summary
Обработка файла .csv с замерами температуры. Курсовой проект по предмету "Программирование на C. Базовый уровень", факультет "Инженер умных устройств", Geekbrains.

**Программа для расчёта статистики по температуре**

*Сборка на Linux* 
```
cd <папка с программой>
make
```
*Запуск на Linux*
```
./temp -f <путь к файлу с данными> 
```
Дополнительные ключи:
-h - вывод справки
-m <номер месяца> - вывести статистику за указанный месяц.

Файл с данными должен быть в формате csv и содержать строки такого формата
```
yyyy;mm;dd;hh;mm;temperature
```
yyyy - год, 4 цифры
mm - месяц, 1-2 цифры
dd - день, 1-2 цифры
hh - час, 1-2 цифры
mm - минута, 1-2 цифры
temperature - температура, 1-2 цифры от -99 до 99

*Пример запуска*
```
./temp -f temperature_small5.csv 
Имя файла temperature_small5.csv
Месяц 1, средняя температура = -47.000000; число замеров = 1
Месяц 1, максимальная температура = -47; число замеров = 1
Месяц 1, минимальная температура = -47; число замеров = 1
Месяц 2, средняя температура = -30.000000; число замеров = 1
Месяц 2, максимальная температура = -30; число замеров = 1
Месяц 2, минимальная температура = -30; число замеров = 1
Средняя температура за год = -38.000000; число замеров = 2
Максимальная температура за год = -30; число замеров = 2
Минимальная температура за год = -47; число замеров = 2
```
В комплекте есть файлы с данными для примера в формате csv.


*Исходные коды*

temperature_calculate_csv.c - основной файл с функцией main()
temp_functions.c - файл с функциями, используемыми в программе
temp_functions.h - файл с заголовками функций программы
Makefile - файл для сборки, содержит команды для сборки программы и очистки папки от исполняемых файлов в случае необходиости
